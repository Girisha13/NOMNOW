# NOMNOW

A full-stack food ordering web application built with the MERN stack.

## Features

- Browse and search food items
- Category-based menu
- Cart management
- User authentication
- Order management
- Admin management
- Stripe payment integration
- Responsive UI

## Tech Stack

- React.js
- Node.js
- Express.js
- MongoDB
- Mongoose
- Stripe
- JWT
- Vite
